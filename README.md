A chess engine in at most 4,096 bytes of Python: 0x88 board, negamax alpha-beta search with quiescence, a transposition table, killer moves, null-move pruning and late-move reductions. It searches to a fixed node budget, never to a clock, so every game replays move for move. Python standard library only.

## Run it

```sh
MAKEFUN_ENV_URL=<competition env url> python3 main.py
```
